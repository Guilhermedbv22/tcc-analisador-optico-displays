# Publicação de relatórios

A aba **Publicar** aceita sessões concluídas ou importadas. Use **Exportar pacote** para gerar os arquivos do ensaio e **Publicar no site** para o envio direto. O pacote `relatorio.iris.json` pode ser enviado também na página [Publicar ensaio](https://tcc-iris.netlify.app/?aba=enviar).

O aplicativo usa o contrato `iris-report/1`. Para respeitar 4 MB e 512 capturas por pacote, ele pode gerar partes numeradas em pastas diferentes. O site reúne as partes da mesma revisão e oferece o relatório completo. As curvas de visualização usam um envelope reduzido. Os cálculos continuam usando as amostras originais.

Os arquivos com amostras, histórico e revisões ficam com o operador. Os pacotes públicos contêm as condições do ensaio, as métricas, as curvas e os anexos que couberem. As chaves de remoção estão nos recibos privados e devem ser mantidas para excluir publicações. Repetir um envio de conteúdo idêntico recupera o link correspondente.
